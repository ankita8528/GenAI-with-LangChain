When building APIs, document extraction systems, or agents, you need language models that return information in **predictable, machine-readable formats** instead of random free-text paragraphs.  
LangChain gives us powerful tools to achieve this.

---

# 📌 Structured Output

In LangChain, *structured output* means getting LLM responses in a **well-defined format** (e.g., JSON) instead of free-form natural language. This makes downstream automation easier and more reliable.

### Example

❌ Free text: Riya is 24 and lives in Gurgaon.

✅ Structured JSON  
```json
{
  "name": "Riya",
  "age": 24,
  "city": "Gurgaon"
}
```

## 📌 Why Structured Output?

Structured output is essential for: 

**Data Extraction** – invoices, forms, medical documents, IDs

**API Building** – predictable JSON for clients

**Agents** – agents require strict formats to reason and act

## 📌 Two Types of LLMs

LangChain treats LLMs based on their ability to output structured data:

| Model Type                                                    | Supports Native Structured Output? | Needs Output Parser? |
| ------------------------------------------------------------- | ---------------------------------- | -------------------- |
| **Structured-output capable LLMs** (GPT-4o, GPT-4.1, GPT-3.5) | Yes                                | No                   |
| **Text-only LLMs** (Llama, Gemma, some local models)          | No                                 | Yes                  |


So we have two strategies:

**1. with_structured_output()** → for models that can generate structured output

**2. Output Parsers** → for models that cannot generate structured output

## 🚀 1. Using with_structured_output()

Models like GPT-4o or GPT-4.1 natively support structured output.
LangChain provides simple wrappers to define structure using:

+ TypedDict
+ Pydantic
+ JSON Schema

### ✅ Using TypedDict
```python
from typing import TypedDict
from langchain_openai import ChatOpenAI

class PersonInfo(TypedDict):
    name: str
    age: int
    city: str

model = ChatOpenAI(model="gpt-4o-mini")
 
structured_llm = model.with_structured_output(PersonInfo)

response = structured_llm.invoke("Extract info: Riya is 24 years old and lives in Gurgaon.")
print(response)
```

### ✅ Using Pydantic
```python
from pydantic import BaseModel
from langchain_openai import ChatOpenAI
 
class Product(BaseModel):
    product: str
    price: float
    category: str

llm = ChatOpenAI(model="gpt-4o")
structured_llm = llm.with_structured_output(Product)

result = structured_llm.invoke("The iPhone 15 Pro costs 134900 INR and is a smartphone.")
print(result)
```

### ✅ Using JSON Schema
```python
schema = {
    "title": "WeatherInfo",
    "type": "object",
    "properties": {
        "temperature": {"type": "number"},
        "condition": {"type": "string"}
     },
    "required": ["temperature", "condition"]
}
model = ChatOpenAI(model="gpt-4o")
structured_llm = model.with_structured_output(schema)

response = model.invoke("Today's weather is 29 degrees and cloudy.")
print(response)
```

## 🚀 2. Output Parsers (For Models Without Structured Output)

If your model cannot emit structured JSON reliably (e.g., Llama, Gemma, Mistral), you can use LangChain’s output parsing utilities.

Common parsers include:

JsonOutputParser

PydanticOutputParser

StructuredOutputParser

CommaSeparatedListOutputParser

### ✅ JsonOutputParser
```python
from langchain.output_parsers import JsonOutputParser
from langchain_openai import ChatOpenAI

parser = JsonOutputParser()

prompt = """
Extract details in pure JSON:
name, age, city
Text: Rahul is 29 and lives in Pune.
"""

llm = ChatOpenAI(model="gpt-3.5-turbo")

raw_output = llm.invoke(prompt).content
parsed = parser.parse(raw_output)
print(parsed)
```

### ✅ PydanticOutputParser
```python
from pydantic import BaseModel
from langchain.output_parsers import PydanticOutputParser
from langchain_openai import ChatOpenAI

class Movie(BaseModel):
    title: str
    year: int
    genre: str

parser = PydanticOutputParser(pydantic_object=Movie)

prompt = (
    "Extract movie information.\n"
    f"{parser.get_format_instructions()}\n"
    "Movie: Inception is a sci-fi film from 2010."
)

llm = ChatOpenAI(model="gpt-3.5-turbo")

raw_output = llm.invoke(prompt).content
movie = parser.parse(raw_output)
print(movie)
```

## 📌 When to Use What

| Model Type                                                    | Supports Native Structured Output? | Needs Output Parser? |
| ------------------------------------------------------------- | ---------------------------------- | -------------------- |
| **Structured-output capable LLMs** (GPT-4o, GPT-4.1, GPT-3.5) | Yes                                | No                   |
| **Text-only LLMs** (Llama, Gemma, some local models)          | No                                 | Yes                  |

## Summary

+ Structured output is critical for predictable AI behavior.
+ Use with_structured_output() when the model supports structured output natively.
+ Use Output Parsers when dealing with simple text-based models.
+ Essential for data extraction, API development, and agentic workflows.
